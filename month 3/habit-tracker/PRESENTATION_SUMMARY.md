# Habit Tracker Presentation Summary

## Problem

Many students and working professionals want to build better routines, but they
forget to track habits consistently.

## Solution

Habit Tracker helps users create habits, mark them complete each day, and review
their completion history.

## Main Workflow

1. User signs up or logs in.
2. User creates a habit.
3. User views habits on the dashboard.
4. User marks today's habit as complete.
5. User checks completion history.

## Tech Stack

- React
- Vite
- React Router
- Express.js
- PostgreSQL
- JWT authentication
- bcrypt password hashing
- CSS

## Key Features

- Signup and login
- Protected user-specific data
- Add, edit, delete habits
- Mark habits complete for today
- Completion history
- Search and filter habits
- Responsive UI
- Error and loading states

## Known Limitations

- No password reset yet
- No streak chart yet
- Deployment configuration is not completed yet
