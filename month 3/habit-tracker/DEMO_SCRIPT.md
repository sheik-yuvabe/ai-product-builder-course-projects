# Habit Tracker Demo Script

1. Open the landing page.

   Say: "This is my Habit Tracker app. It helps users build daily routines."

2. Go to Login.

   Say: "Users can sign up or log in. Passwords are hashed in the backend."

3. Sign up with a test account.

   Example:

   ```text
   Name: Demo User
   Email: demo@example.com
   Password: secret123
   ```

4. Open Dashboard.

   Say: "This dashboard shows only the logged-in user's habits."

5. Add two habits.

   Example:

   ```text
   Drink water
   Read for 20 minutes
   ```

6. Mark one habit complete.

   Say: "This completion is saved in PostgreSQL for today's date."

7. Use search or filters.

   Say: "The user can search habits and filter active or completed habits."

8. Edit one habit.

   Say: "Users can update habit names."

9. Delete one habit.

   Say: "Users can also remove habits they no longer need."

10. Open History.

    Say: "The history page shows completed habits from the database."

11. Logout.

    Say: "Protected routes require login, so each user sees only their own data."
